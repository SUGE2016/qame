# QAME Lobby Design System

来源：ui-ux-pro-max。对战大厅选 **Swiss Modernism 2.0**（网格、高对比、单一强调色），不用 Retro-Futurism（无障碍差）。

- Font: Plus Jakarta Sans
- Primary `#0369A1` / CTA `#0F766E` / Danger `#B91C1C`
- Background `#F4F7FA` / Surface `#FFFFFF` / Text `#0F172A`
- 8px 间距；图标用 SVG，不用 emoji
- 布局：顶栏 + 左侧游戏 + 右侧对局表
