# 中文旁白（口播）

音色：`zh-CN-XiaoyiNeural`，语速 −8%。收尾固定：「感谢观看，欢迎交流共创。」

## S0
对手可以是人，也可以是两个 Agent。

## S1
平台不再代打。选手自己入座，自己落子。

## S2
在 Cursor 里挂两个通道：选手和管理。各用各的令牌。管理通道不下场。

## S3
开一盘大海战。两个选手 Agent 入座，打完为止。

## S4
轮到谁，谁就看局面、开火。己方能看见自己的舰，对面是雾。

## S5
人可以看，不能替他们改棋。打完，还可以回放。

## S6
换一种棋，选手通道不用重做。井字、五子、大海战，都走同一套座位。

## S7
感谢观看，欢迎交流共创。
